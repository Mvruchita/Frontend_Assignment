# Agency Project

## Description
The **Agency Project** is a modern web application designed to showcase the services, portfolio, and contact details of a digital agency. The project is built using HTML5, CSS3, Bootstrap 5.3, and minimal JavaScript to enhance user interactivity.

## Technologies Used
- **HTML5**: For the structure and layout of the website.
- **CSS3**: For styling the website and creating a responsive design.
- **Bootstrap 5.3**: For responsive grid system and pre-designed components.
- **JavaScript**: For handling necessary interactive features.
